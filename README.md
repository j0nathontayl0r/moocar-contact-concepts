# Moocar contact page design study

Three independent, responsive contact-page concepts for review. This repository does not replace or operate the live Moocar website.

- [A — Tidy-up](A-tidy-up.html): conservative rework
- [B — Quote-first](B-quote-first.html): recommended enquiry flow
- [C — Guided](C-guided.html): step-by-step enquiry
- [Comparison board](Moocar%20Contact%20Options.html): phone/tablet/desktop previews

**Important:** Forms are demos. They do not send enquiries or collect data. Phone, email and external links go to public Moocar contact channels. Design prototypes reference some image assets hosted on the current Moocar site; those assets remain with their respective owner. This is a review artifact, not a licensed production template.
